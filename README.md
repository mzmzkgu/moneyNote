# 내 가계부 (moneyNote)

지출을 기록하고 분류/결제수단별로 통계를 볼 수 있는 개인 가계부 앱 (React, CDN 로드 방식).

## 구성
- `index.html` — React + Babel(브라우저에서 바로 JSX 변환)으로 작성된 단일 페이지 앱
- `index_v1.html` — 이전 버전 스냅샷

## 주요 기능
- 지출 / 통계 / 설정 3개 탭
- 월별 지출 입력(날짜·시간·금액·사용처·결제수단·분류·비고), 정산완료 체크
- 결제수단별·분류별 지출 비중 파이차트, 지출 Top5, 월간 요약
- 결제수단/분류 직접 추가·삭제 관리
- 데이터는 전부 브라우저 localStorage에만 저장 (서버 없음) — JSON 백업/복원, 엑셀(.xlsx) 내보내기 지원
- 다크/라이트 테마, 글자 크기 조절
